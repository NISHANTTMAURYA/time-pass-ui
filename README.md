# time-pass-ui

Interactive WebGL & Three.js 3D Portfolio experience for **Vinish Rexson** (Full-Stack Web & AI/ML Developer).

## ✨ Features
- **WebGL & 3D Interactive Graphics**: Custom Three.js scenes, real-time lighting, interactive GLSL shaders, and 3D models.
- **Interactive UI & Sounds**: Lenis smooth scrolling, GSAP ScrollTrigger animations, Web Audio sound effects, and custom magnetic cursor.
- **Projects & Repertoire**: Features SIH 2024 Unreal gaming, SunHacks 2025 GenAI platform, MentorConnect, MedSafe, and AI Trading models.
- **Multi-language**: Built-in dynamic localization (English / German).

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/NISHANTTMAURYA/time-pass-ui.git

# Navigate into directory
cd time-pass-ui

# Run locally using python
python3 -m http.server 3000

# Or using Node
npx serve . -l 3000
```
Then open `http://localhost:3000` in your browser.
